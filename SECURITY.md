# Security policy

waveUSBCAN_b is experimental kernel-space software for USB-CAN adapters. Kernel bugs can affect system stability. CAN traffic on mobility devices can be safety-critical.

## Reporting

Please report security or safety-relevant issues privately first if possible. Include:

- kernel version and distro,
- adapter USB ID,
- exact modprobe options,
- dmesg logs,
- whether the issue occurred on an isolated bench bus or a live device bus.

## Safety boundary

Do not publish instructions that cause uncontrolled movement or unsafe behavior on a wheelchair or other vehicle.
